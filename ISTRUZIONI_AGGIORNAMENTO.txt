STU GYM TRACKER 2.3 — OBIETTIVO CALORICO GIORNALIERO

Novità: nella sezione Cibo trovi un obiettivo calorico giornaliero modificabile manualmente. Il riepilogo mostra calorie assunte, obiettivo, calorie rimanenti (o superate), barra di avanzamento e ripartizione delle calorie per colazione, spuntini, pranzo e cena. Il totale si aggiorna quando aggiungi o elimini alimenti.

Aggiornamento: esporta prima un backup JSON. Estrai lo ZIP e carica nella root del repository GitHub tutti i file inclusi, sostituendo quelli esistenti; esegui Commit changes e attendi il completamento verde di Pages. La chiave localStorage resta stuGymTracker_v1 e i dati esistenti vengono mantenuti. Il service worker usa una nuova cache per distribuire la versione aggiornata.
